ABOUT THE PROJECT

This project is a habit tracker built with React and  It includes user authentication, persistent storage, and a clean, responsive interface designed to replicate a real-world productivity application.
It also includes various features such as a streak tracker and a progress bar to improve the user experience.

Getting Started

1. Clone the repository

`git clone https://github.com/your-username/habit-tracker.git`

`cd habit-tracker`

2. Install dependencies

`npm install`

3. Start the development server

`npm run dev`

4. Open the application

Once the server is running, open your browser and go to:

`http://localhost:5173`
